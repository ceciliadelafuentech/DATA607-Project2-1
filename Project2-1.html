Overview

The first dataset I chose for Project 2 is a table from Wikipedia comparing greenhouse gas emissions associated with charging plug-in electric vehicles in different U.S. cities. The data comes from a Union of Concerned Scientists study. Although this is not a “wide” dataset, it is an example of untidy data. The table contains hierarchical and grouped information. The cities are grouped into categories such as “Best,” “Better,” and “Good,” but these categories are presented as section headings rather than as a variable for each city. Some rows contain city data, while other rows contain additional headings such as “Tailpipe CO2” and “Upstream GHG.” This makes it difficult to treat each row as a consistent observation with the same variables. I will restructure the data so that each city is represented through each variable stored in its own column. For the analysis, I could answer the question: “How do the greenhouse gas emissions associated with plug-in electric vehicles vary across U.S. cities?”

Keep the rating categories and fill them down to match each city with its correct rating. Remove rows without city names, convert the emissions and percentage reduction values to numeric format, and select the four columns needed for analysis.

emissions_long <- df |>
  mutate(
    rating = if_else(
      trimws(rating) %in% c("Best", "Better", "Good"),
      trimws(rating),
      NA_character_
    )
  ) |>
  fill(rating, .direction = "down") |>
  filter(!is.na(city), trimws(city) != "") |>
  mutate(
    emissions_mpg = parse_number(as.character(emissions_mpg)),
    percent_reduction = parse_number(as.character(percent_reduction))
  ) |>
  select(rating, city, emissions_mpg, percent_reduction)

Calculate summary statistics for the 16 cities, including the number of cities, average, lowest, and highest emissions, and average percentage reduction. The results provide an overview of the differences in estimated PEV emissions.

emissions_summary <- emissions_long |>
  summarise(
    number_of_cities = n(),
    average_mpg = mean(emissions_mpg, na.rm = TRUE),
    lowest_mpg = min(emissions_mpg, na.rm = TRUE),
    highest_mpg = max(emissions_mpg, na.rm = TRUE),
    average_reduction = mean(percent_reduction, na.rm = TRUE)

Conclusion

The dataset was tidied by separating the city names, emissions-equivalent fuel economy values, percentage reductions, and rating categories into separate variables.

The analysis compared estimated plug-in electric vehicle (PEV) greenhouse gas emissions across 16 U.S. cities using an emissions-equivalent fuel economy measure. Juneau, Alaska had the highest value at 112 mpg-US, followed by San Francisco at 79 and New York City at 74. Denver had the lowest value at 33 mpg-US, followed by Wichita, Kansas at 35 and St. Louis, Missouri at 36. The results show considerable variation across cities. Because the measure accounts for emissions associated with electricity generation, these differences show how the environmental benefits of driving a PEV can differ based on where the vehicle is charged.

One limitation is that the analysis uses outdated estimates provided in the original dataset, which may not reflect current electricity generation. Further analysis could compare these results with more recent data to see whether the differences between cities have changed.
